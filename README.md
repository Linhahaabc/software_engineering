# AI 个性化私人健康管理系统
软件工程课程小组作业 | 6人团队

## 团队分工
- FE-A：前端核心页面、组件、图表
- FE-B：前端页面、WebSocket、动效
- BE-A：后端接口、数据库、认证
- BE-B：AI接口、异步任务、WebSocket
- CV：Stable Diffusion、LoRA、生图调优
- FS：基础设施、联调、测试、文档

## 技术栈
- 前端：Vue3 + Vite + Element Plus
- 后端：Python + FastAPI
- AI：DeepSeek + Stable Diffusion
- 数据库：PostgreSQL
- 中间件：Redis + Celery + MinIO

## 核心模块
1. 多模态健康数据采集
2. 个性化风险评估与预警
3. 智能健康计划生成
4. 实时监测与异常提醒
5. 健康知识推送
6. 医疗机构对接
7. 健康趋势分析与可视化
8. 时光魔镜视觉预警
